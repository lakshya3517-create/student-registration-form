# Student Registration Form

A simple front-end project that collects student details and validates them in the browser.

## Features
- Required-field validation (name, date of birth, gender, email, phone, course, year, confirmation)
- Email format check
- Phone check: exactly 10 digits, starting with 6-9
- Inline error messages, live re-validation and focus on the first error
- Summary of the submitted details shown on success (no data is sent anywhere)

## Tech
HTML, CSS, JavaScript (no libraries)

## Run locally
Open `index.html` in a browser.
